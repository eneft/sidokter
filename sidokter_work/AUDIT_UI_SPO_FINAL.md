# AUDIT UI SPO — FINAL CHECKLIST

Perbaikan UI SPO dikunci berdasarkan 13 poin audit:

1. Header compact.
2. Informasi berulang di bagian atas dikurangi.
3. Banner Perpustakaan SPO dipadatkan menjadi heading workspace.
4. Informasi akses hirarki dipadatkan menjadi satu baris.
5. Label "Semua" diperjelas menjadi "Semua Hirarki".
6. Hierarki visual tombol diperjelas; + SPO Baru menjadi aksi utama.
7. Label "Daftarkan SPO Baru" dipersingkat menjadi "+ SPO Baru".
8. Search/filter diringkas agar fokus pada dokumen.
9. Search mendukung judul dan nomor: "Cari judul atau nomor SPO...".
10. Daftar SPO menggunakan layout full-width; Nomor dan Judul menjadi informasi utama.
11. Jumlah dokumen ditampilkan.
12. Jenis SPO BARU/EXISTING/RIVIU dan status dibuat jelas.
13. Nomor Terbit bukan dropdown; tombol membuka modal. Isi utama modal hanya Nomor SPO dan Judul SPO, dengan pencarian nomor/judul.

Aturan bisnis terkait UI:
- Nomor yang sudah USED tidak ditampilkan sebagai Nomor Terbit tersedia.
- SPO Existing/Riviu tidak boleh diperlakukan sebagai SPO Baru hanya karena masuk alur Riviu.
- Nomor existing/legacy tetap dipertahankan.
