# Setup Administrator Pertama

SIDOKTER tidak memerlukan `SIDOKTER_BOOTSTRAP_SECRET`.

Pada instalasi baru, buka halaman login dan pilih **Setup Administrator Pertama**. Buat password Administrator minimal 12 karakter dengan huruf besar, huruf kecil, angka, dan simbol.

Endpoint setup hanya dapat digunakan ketika belum ada Administrator. Setelah Admin pertama dibuat, setup otomatis terkunci.

Tidak ada credential default yang dikemas dalam ZIP.
