# SIDOKTER Login 1.0.8 — Single Precision Composition

## Target
Use the legacy login geometry as the visual reference while retaining the RSUD sketch background and coded SIDOKTER branding.

## Rules
- One centered composition for desktop, tablet, and mobile.
- No desktop split panel on login.
- Login shell max width: 560px.
- Branding width: 80% of shell.
- Official RSUD logo remains an asset; SIDOKTER remains CSS/coded text.
- No white frame around the branding lockup.
- Login card: translucent white (93%), no backdrop blur.
- Background: full viewport, opacity 100%, no blur.
- Responsive breakpoints only protect physical fit; they do not create a separate visual design.
- Authentication, Firebase, session, API, and workflow code are untouched.
